 Controle de EPI - Indústria Têxtil
Sistema web desenvolvido para gerenciar o empréstimo de EPIs e o cadastro de colaboradores em ambiente industrial.
 Funcionalidades
•	Cadastro de colaboradores
•	Cadastro de equipamentos (EPIs)
•	Controle de empréstimos e devoluções
•	Atualização automática de estoque
•	Dashboard com indicadores
•	Histórico de movimentações
 Como Executar
1.	Instale o MySQL (senha padrão: root123)
2.	Crie o banco de dados: CREATE DATABASE gepi; USE gepi;
3.	Execute o script SQL do projeto
4.	No terminal, execute: npm install
5.	Inicie o servidor com: node server.js
6.	Acesse no navegador: http://localhost:3000
 Tecnologias
•	Node.js
•	Express
•	MySQL
•	HTML, CSS e JavaScript
